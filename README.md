# Riversol Summer Sale Landing Page

Sales-oriented landing page for [Riversol](https://www.riversol.com/) featuring a limited-time Summer Sale.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Notes

- Product imagery and prices are **placeholders** — replace with live catalog assets/links.
- Countdown targets the upcoming Sunday 11:59 PM local time for demo urgency.
- Brand links in the footer point to riversol.com.
